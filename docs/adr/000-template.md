# ADR-NNN: <short decision title>

- **Status:** proposed | accepted | superseded by ADR-NNN
- **Date:** YYYY-MM-DD

## Context

What forced a decision here. The constraints that were real at the time —
technical, product, or operational. Written so it still makes sense to someone
reading it a year later without the surrounding conversation.

## Decision

What was chosen, stated plainly and in the present tense.

## Alternatives considered

Each one with the reason it lost. An ADR whose alternatives are all obviously
bad is not documenting a decision, it is justifying one.

## Consequences

What this makes easy, what it makes hard, and what now has to be true for the
system to keep working. Include the cost, not only the benefit.
